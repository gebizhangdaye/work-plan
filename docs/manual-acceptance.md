# 人工验收单

自动化部分已经覆盖：`npm run check`（typecheck + eslint 门禁 + 44 个 Vitest 用例 + 三目标构建）。
下面这些是**只有真机 GUI 才能验**的项，请逐条打勾。启动方式：`npm run dev`，或直接双击 `release\workplan-win-x64.exe`。

## 1. 启动与数据

- [ ] 首次启动后 `%APPDATA%\work-plan\` 下出现 `workplan.db`、`attachments\`、`backups\`
- [ ] 控制台打印 `[boot] schema v1 数据目录 ...` 与 `[boot] 已备份 workplan-....db`
- [ ] 关掉程序再打开，之前记的内容都还在
- [ ] 把 exe 复制到别的目录再运行，数据仍然读得到（数据不跟 exe 走）
- [ ] 双击第二个 exe 实例：不会开新窗口，已有窗口被叫到前台

## 2. 三档泳道

- [ ] 三列标题是「加急 / 今天 / 以后」，列头显示「N 在办」，有逾期时追加「· N 逾期」
- [ ] 列底输入框回车即建一条，落进所在档
- [ ] 勾选复选框：卡片划线并沉到本列底部；再点一次回到在办并回到原排序位置
- [ ] 同列内上下拖动，顺序按松手位置生效
- [ ] 跨列拖动后卡片进入目标列
- [ ] 点卡片右下角 `→今天` / `→以后` / `→加急`：档位循环切换

## 3. 计划日与逾期

- [ ] 详情里选一个过去的日期并保存 → 卡片标题出现红色「逾期」角标，且排到本列最前
- [ ] 选今天的日期 → 排在逾期之后、无日期之前
- [ ] 选未来的日期 → **仍然显示**（只多一个日期徽标，不会被藏起来）
- [ ] 日期填错（比如 2 月 30 日）会被拒绝保存，并提示「计划日必须是真实的 YYYY-MM-DD」

## 4. 聊天截图（核心）

- [ ] 用微信/QQ 截图工具截一块 → 点开卡片 → 光标放在「记录」框 → `Ctrl+V`：缩略图出现在卡片附件墙
- [ ] 剪贴板里只有文字时按 `Ctrl+V`：文字正常进输入框，不会报「没有图片」以外的异常
- [ ] 同一张图在同一个卡片里粘两次：只生成一个 png 文件（看 `attachments\` 目录）
- [ ] 拖 2 个本地图片文件进「记录」框：生成 2 个附件，**原文件还在原位置没被动过**
- [ ] 拖一个非图片文件（如 .txt）：不产生附件，也不报错
- [ ] 超大截图（长边 >2000px）落盘后像素被压到 2000 以内
- [ ] 删掉卡片：`attachments\` 里没人引用的 png 被清掉；被别的卡片引用的同名文件**不被删**

## 5. 大图与裁剪

- [ ] 点缩略图弹出大图，`Esc` 或点空白关闭
- [ ] 「显示所在文件夹」能在资源管理器里选中那个 png
- [ ] 「裁剪这一块」→ 拖动选区、拉「放大」滑杆 → 「存为新截图」：附件墙多出 1 张裁出来的图，**原图那张还在**
- [ ] 缩略图鼠标悬停提示「这是裁剪出来的图」

## 6. 搜索与标签

- [ ] 搜索框输入中文词（如「支付回调」）实时过滤三列；命中范围包括标题、正文、标签名
- [ ] 两个词「导出 csv」= 同时满足才显示
- [ ] `Esc` 清空搜索后三列恢复全量
- [ ] 卡片详情里输入标签名回车即建并挂上；操作栏第二行出现该标签 chip 与计数
- [ ] 点两个 chip = AND 过滤；「清除筛选」恢复

## 7. 导出

- [ ] 齿轮弹层「导出为 Markdown 文档」：文件里三档按 加急→今天→以后 排列，完成项是 `- [x]`，正文缩进，截图是 `![](attachments/...)` 相对路径
- [ ] 齿轮弹层「导出为 CSV 表格」：Excel 打开中文不乱码，8 列对齐，正文里的逗号/换行/引号不撑破单元格
- [ ] 取消保存对话框：不产生文件，也不报错

## 8. 标题栏、窗口与托盘

- [ ] 主窗**没有系统标题栏**：顶上一条自定义标题栏，左起 logo + 工作计划 + 今天 + 菜单条，右侧三个按钮 最小化 / 最大化还原 / 关闭到托盘（**Windows**；macOS 上三个自绘按钮整个不渲染，红绿灯在左上，见 §14）
- [ ] 菜单条是**标题栏里的 文件 / 编辑 / 视图 / 帮助**（不再是系统菜单栏）：点字打开下拉，打开后横向移到别项直接切换，Esc / 点外面 / 窗口失焦关闭
- [ ] 文件：最小化到托盘 `Ctrl+M`、退出工作计划 `Ctrl+Q`；编辑：撤销/重做/剪切/复制/粘贴/全选；视图：重新加载/强制重新加载/实际大小/放大/缩小/开发者工具/全屏；帮助：关于工作计划
- [ ] 菜单项右侧显示快捷键，分隔线断段；点「视图 → 放大」整页缩放生效，`Ctrl+0` 回到实际大小
- [ ] 点「帮助 → 关于工作计划」直接打开设置弹窗并停在「关于」分区（与齿轮是同一个弹窗，不开第二套）
- [ ] 按住标题栏空白处能拖动窗口（实测拖约 113px，窗口位移跟手到像素）；双击标题栏最大化
- [ ] 最大化后「最大化」按钮换成「向下还原」图标（主进程推 maximizeChanged），实测 1332×866 ↔ 1453×925 来回都对
- [ ] 最大化时内容不被裁：logo、三个按钮、三列都完整可见
- [ ] 关窗口（点标题栏 ×）程序不退出，托盘里图标还在；点托盘图标恢复窗口
- [ ] 托盘菜单「退出」或设置弹窗「关于 → 退出工作计划」才真的退出（任务管理器里没有残留进程）
- [ ] 系统深色模式下界面自动是深色（跟随 `prefers-color-scheme`，没有手动主题开关）
- [ ] 窗口缩到 980×620 以下时列内可滚动，不出现横向裁切

## 9. 设置与备份

- [ ] 操作栏只有三样东西：检索框、看板/小窗分段控件、一个齿轮；没有第四个并列入口
- [ ] 齿轮开的是**居中模态弹窗**，左侧菜单三个分区：导出 / 数据与运行 / 关于，当前分区白底 + 加粗
- [ ] 「导出」分区两项：Markdown 文档、CSV 表格，点完弹窗自动关闭并回到看板提示结果
- [ ] 「数据与运行」分区的数据目录、任务数、截图张数与体积、数据库体积和实际一致；数据目录一行放得下、不折成两行
- [ ] 「关于」分区是 logo + 版本 + 本地离线说明 + 退出工作计划按钮，按钮按内容宽度不拉满
- [ ] `Esc` 与点遮罩都能关弹窗
- [ ] 勾「开机自启」后 `reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 能看到项；取消勾后消失（Windows；macOS 走登录项，见 §14）
- [ ] 手动把 `backups\` 里某份复制成 `workplan.db` 能恢复数据
- [ ] `backups\` 里的份数不超过 5

## 10. 汉化与语言

- [ ] **Windows**：系统原生菜单栏整个撤掉（`Menu.setApplicationMenu(null)`），菜单只在标题栏那一份；`Ctrl+C/V/X/Z/A` 仍走输入框默认（实测 Ctrl+A 能选中搜索框文字），应用级快捷键由标题栏菜单自己接（实测 `Ctrl+0` 恢复缩放、`Ctrl+Q` 退出）。macOS 不能撤，那份菜单栏见 §14
- [ ] 界面里没有 File / Edit / View / Window / Help 或 Undo / Cut / Copy / Toggle Developer Tools 这类英文项
- [ ] 设置弹窗「关于」全中文；导出保存对话框标题是「导出工作计划」
- [ ] 点「计划日」输入框右侧图标：弹出的原生日历是中文（月份/星期/今天），格式显示为 年/月/日
- [ ] 设置弹窗「导出」分区点完的保存对话框：文件类型下拉显示「Markdown 文档」或「CSV 表格」
- [ ] 把 Windows 显示语言临时改成英文再启动一次程序，以上仍然全中文（语言是钉死的，不跟系统飘）
- [ ] 中文正文没有被英文拼写检查画红波浪线

## 11. 小窗置顶模式

- [ ] 点操作栏分段的「小窗」：窗口收成约 420×560 贴在屏幕右上角，且**别的窗口盖不住它**（`WS_EX_TOPMOST` 已实测置位；macOS 上对应 `setAlwaysOnTop(true, 'floating')`）
- [ ] 三档合并成**一条**列表，顺序是 加急 → 今天 → 以后，档内逾期在前、完成沉底
- [ ] 每条左侧有色条 + 小色块区分档位：加急红、今天蓝、以后灰；上方计数 chips 也是同三色
- [ ] 行内复选框能直接勾完成；勾完后该条变灰划线并沉到所属档位末尾
- [ ] 点某条的文字：回到三列看板并自动打开这条的详情抽屉
- [ ] 小窗里输入搜索词，列表实时收窄；清空恢复
- [ ] 逾期条目显示红色「逾期」小标签与 `MM-DD`
- [ ] 点分段「看板」后窗口回到原来的尺寸与位置（实测 1320×860 @ 60,26 精确还原）
- [ ] 小窗里**没有**最小化/收起入口（按需求去掉）：要收起来先点「看板」回大窗，再 `Ctrl+M` 或点托盘
- [ ] 小窗开着时点托盘图标或再次双击 exe，回到看板而不是冒出第二个小窗

## 14. macOS 差异（这一节只能在 Mac 上打勾）

上面 §1–§13 除了标注 Windows 的几条，macOS 上应当同样成立。下面这些是两边行为本来就该不同的地方。
出包前先跑 `npm run icons && node scripts/probe-mac-assets.mjs && npm run check`，再 `npm run dist:mac:arm64`（或 `:x64`）。

**窗口与红绿灯**

- [ ] 标题栏左上是原生红绿灯，垂直居中在那条 40px 里（代码里是 `{ x: 12, y: 13 }`）；logo 让到灯组右边且有呼吸位（`.titlebar-mac` 的 78px 是**推导值不是实测值**，要逐元素量 `clientWidth` 校准，别目测）
- [ ] **若灯压根不出现**：是 `frame: false` 与 `titleBarStyle: 'hiddenInset'` 在这版 Electron 上没按预期叠加（`mainWindow.ts:33` 的 mac 分支同时给了这两个）。退路是 mac 分支去掉 `frame: false` 只留 `titleBarStyle` + `trafficLightPosition`，再确认那条 40px 的 drag 区高度没被系统标题栏顶掉
- [ ] 三个自绘窗口按钮整个不出现；黄=最小化、绿=缩放（按住 ⌥ 点绿钮进全屏）、红=关闭到托盘
- [ ] 按住标题栏空白仍能拖动。**重点验**：整条是 `-webkit-app-region: drag`，Mac 上 drag 区有可能吃掉红绿灯的点击，表现为灯看得见但点不动。真出现就在灯组那一段上加一条 `no-drag` 的窄条，别去改 `titleBarStyle`
- [ ] 绿灯进全屏（独立 Space）再退回来，界面不残留错误状态；小窗在主窗全屏时是否还浮在上面

**菜单栏与快捷键**

- [ ] 系统菜单栏有 工作计划 / 编辑 / 视图 / 窗口 四项，标题栏里那条菜单条**仍然在**（两份不重叠：一份在屏幕顶，一份在窗口里）
- [ ] `⌘Q` 真退出（任务管理器口径：`ps aux | grep work-plan` 没有残留）；`⌘H` 隐藏；`⌥⌘M` 收进托盘；`⌘M` 最小化到 Dock
- [ ] §10 那条「没有英文项」在这份原生菜单上同样成立：不能冒出 About / Services / Hide Others / Enter Full Screen / Minimize / Toggle Developer Tools
- [ ] 编辑菜单里没选区时「剪切/复制」是灰的（这条是叶子 role 带来的原生判定）；搜索框里 ⌘A 能全选
- [ ] 标题栏菜单条右侧显示的是 `⌘M`/`⌘Q`/`⌥⌘I`/`⌃⌘F` 这一串，不是 `Ctrl+…`；按显示的那一串确实能触发，且**不会一次触发两遍**（macOS 下渲染层整个不兜快捷键）
- [ ] 正文字体落到 -apple-system + 苹方，不会去渲 Segoe；`⌘ ⌥ ⌃ ⇧` 四个符号都不是豆腐块

**Dock、托盘、数据**

- [ ] 红钮收窗后点 **Dock 图标能唤回**（这条改之前是死的）；小窗开着时点 Dock 不许把用户踢回看板
- [ ] 菜单栏那个图标是单色模板图，跟随菜单栏明暗自动反色，不是一块蓝色色斑；`@2x` 在 Retina 上不糊
- [ ] 带 context menu 的 `NSStatusItem` 可能不触发 `tray.on('click')`（点图标弹菜单而不是唤回）。唤回不靠它兜底——托盘菜单第一行就是同一个动作，验一下那行有效
- [ ] 设置「数据与运行」里数据目录显示 `~/Library/Application Support/work-plan`，`ls` 对得上；每次启动的备份在 `backups/` 里且不超过 5 份
- [ ] 勾「开机自启」后系统设置 → 通用 → 登录项 里出现本应用（未签名 ad-hoc 包不保证挂得上，挂不上就按弹窗里那句文案处理，别当成功）

**功能与首启放行**

- [ ] 微信/钉钉截图后 `⌘⌃⇧4` 之类截一张，回到条目 `⌘V`：**截图进得来**（Mac 的截图贴板主要是 TIFF，代码里 `IMAGE_TYPES` 已经带 `image/tiff`，剩下要验的是 `nativeImage.createFromBuffer` 能不能解）；解不出来就在 `clipboardIngest.ts` 里打一行 `entry.types` 看真实 MIME 串
- [ ] 拖本地图片进条目、裁剪、`打开所在文件夹`（走 `shell.showItemInFolder`）、导出 CSV 用 Numbers/Excel for Mac 打开不乱码
- [ ] Finder / Dock / `⌘Tab` 里的图标是这份包自带的 `icon.icns`，不是通用白纸图标
- [ ] 首次双击未签名的 `工作计划 0.1.0 arm64.dmg`：预期被 Gatekeeper 拦。放行两条路任选——`xattr -dr com.apple.quarantine "/Applications/工作计划.app"`，或 系统设置 → 隐私与安全性 → 仍要打开（Sequoia 起右键「打开」那一套已经不灵了）
- [ ] `arm64` 包装到 Apple Silicon、`x64` 包装到 Intel 机器各自能起（没有 universal 包：npmmirror 上 `darwin-universal.zip` 是 404）
