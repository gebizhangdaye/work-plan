工作计划 · 使用教程

它是什么，怎么想这件事

工作计划是一个 Windows 桌面待办板：三条泳道（加急 / 今天 / 以后）、能记文字、能直接贴聊天截图，数据全部留在你自己的机器上。没有账号、没有云同步、没有遥测，断网也照常工作。

它刻意只做三档，不做「高 / 中 / 低」，也不做时间块。因为待办工具最容易坏在两个地方：优先级通胀（最后全是「高」），以及记录成本高于收益（截图要另存、要起名、要找回来）。所以这里的规则很少：

  • 档位回答「什么时候必须动它」，不回答「它有多重要」。
  • 截图和文字同属一条记录，需求是微信里说的，就让它以微信截图的形式待着。
  • 过滤器只帮你少看，不替你决定什么不算数：计划日过期了条目照样显示，只是标红并排到最前。
适合谁事情多到需要一直看得见、又常常「证据在聊天记录里」的人。需要甘特图、需要多人协作的场景，它不是为这个设计的。

安装与首次启动

  1. 下载 workplan-win-x64-0.1.1.exe（免安装 portable，约 97 MB），放到任意目录。
  2. 双击运行。未签名的 exe 首次启动会出现 SmartScreen 提示，点「仍要运行」。
  3. 第一次启动会把自己解包到临时目录，比后续启动慢几秒，属正常。
  4. 窗口打开后即可使用；数据目录 %APPDATA%\work-plan 会在首次启动时自动创建。

想开机自动运行：打开 设置 → 数据与运行，勾选「开机自启」。

换存放位置要注意免安装版把「开机自启」指向 exe 的当前路径。移动或改名之后自启会失效，重新勾一次即可。

系统要求

项目 说明
系统Windows 10 / 11，x64
运行时自带，无需另装 Node 或 VC++ 运行库
权限普通用户即可，不弹 UAC
网络不需要

界面导览

窗口从上到下分四层，每层职责单一：

区域 里面有什么
标题栏logo 与应用名、今天日期、文件 / 编辑 / 视图 / 帮助菜单条，右侧是最小化、最大化还原、关闭到托盘
操作栏检索框、看板 / 小窗视图切换、设置齿轮
标签行只在已有标签时出现：过滤按钮 + 各标签 chips，chip 尾巴的数字是挂了它的条目数（含已完成），多点为 AND
看板三条泳道，列头带档位色与计数，列底是「记一条，回车入库」

点任意卡片，右侧滑出详情抽屉：标题、元信息（计划日与档位并排）、记录、标签、截图墙，底部是保存 / 删除与最近更新时间。抽屉里改档位是就地改，不用回到列上拖。

记一条与勾完成

  1. 点进目标列底部的输入框（想记到「加急」就点加急列的框）。
  2. 写完直接回车，条目立即入库并留在该列。
  3. 要补上下文：点开这张卡片，在「记录」框里写正文。
  4. 做完了：点卡片左侧的复选框。条目变灰划线，沉到本列底部，按完成时间倒序排列。
  5. 再点一次复选框可以撤回未完成状态。
快速框只收标题它是单行输入，回车即入库。正文、计划日、标签、截图都在卡片详情里补——先记下来比记完整更重要。

删除一条

点开卡片 → 详情抽屉底部「删除」。删除条目时，它独占的截图文件会按引用计数回收；被别的条目共用的那张不会被删。

三档与拖拽排序

三条泳道固定为 加急 / 今天 / 以后，顺序恒为加急 → 今天 → 以后。

  • 列内排序：在同一列里上下拖动卡片，松手位置即新顺序。
  • 跨列改档：把卡片拖到另一列，档位随之改变，落点决定它在目标列里的位置。
  • 不想拖：点卡片右下角的 → 以后 按钮，按 加急 → 今天 → 以后 循环切档；或在详情抽屉里直接点三个档位按钮。

排序用间隙编号存储，拖动只写它自己那一条；当编号间隙被反复插入耗尽时，整列会自动归一化重排一次。

筛选状态下的拖拽列表被检索或标签过滤过也能拖。落点按「它前面那条卡片」定位，所以即使中间藏着被过滤掉的条目，顺序也不会算错。

计划日与逾期

  1. 点开卡片，在「元信息」里选计划日——粒度到「天」，不用排时间块。
  2. 日期控件是系统原生的中文日历，格式显示为 年/月/日。
  3. 没想好就留空：留空的条目永远不会被判成逾期。

判定规则只有一条：计划日 < 今天 且 未完成 即为逾期。逾期条目会：

  • 标题下出现红色 逾期 小标记，并显示计划日 MM-DD；
  • 在本列里排到最前（列头同时显示「N 逾期」）；
  • 在小窗的合并列表里同样排在前面。
计划日不做隐藏它只影响排序与高亮，不会把任何条目从看板上摘掉。今天做不完的事仍然看得见，这是刻意的。

粘贴与拖入截图

微信、QQ 里截好图，直接到卡片的「记录」框里 Ctrl+V：

  • 剪贴板里是图片 → 落盘成附件，出现在下方截图墙，正文不受影响。
  • 剪贴板里是文字 → 照常粘贴成文本，不需要切换任何模式。
  • 也可以把图片文件从资源管理器拖进「记录」框；原文件不会被移动或改名，应用拷一份自己的副本。

存储与去重

  • 附件按 attachments\YYYY\MM\<内容哈希前 8 位>.png 落盘，库里只存相对路径。
  • 同一张图重复粘贴只存一份；两张不同的图各自独立。
  • 长边超过 2000 像素会自动缩放（微信 4K 截图通常几 MB，缩放后仍然读得清）。
  • 截图墙里点 所在文件夹 可直接在资源管理器里定位这张图。

灯箱与局部裁剪

  1. 点截图墙里的缩略图，进入灯箱（大图）。
  2. 底部显示这条记录的标题与原图尺寸，旁边是 所在文件夹 与 裁剪这一块。
  3. 点「裁剪这一块」→ 拖动选区框住你要留的段落，用「放大」滑杆调整倍率。
  4. 点 存为新截图：裁出来的图作为一条新附件出现在截图墙上，原图那张保留不动，并记着自己是从哪张图裁的。
  5. 按 Esc 或点空白处退出灯箱。

全文检索

操作栏的检索框是中文可用的即时过滤：

  • 空格分词，词与词是 AND：输入「导出 csv」= 同时命中两个词才显示。
  • 命中范围：标题、正文、标签名。
  • 不区分大小写；输入即时生效，无需回车。
  • 按 Esc 一键清空检索条件。

检索只影响「看得见哪些」，不影响数据本身；被过滤掉的条目依然存在于各自的泳道里。清空检索即恢复全量。

为什么不是模糊搜索检索是内存里的分词与匹配，不建索引、不装分词器。代价是它不做拼音、错别字纠正；好处是它零依赖、零维护，也不会有索引和实际数据不一致的问题。

标签与项目分类

  1. 点开卡片，在「标签」框里输入标签名，回车即建即挂，标签行当场多出这个 chip。
  2. 同名标签自动复用，颜色由标签自己带着，卡片、chips、小窗色块三处一致。
  3. 标签行上点某个 chip 即按它过滤；多点几个是 AND（同时具备才显示）。
  4. 要摘掉：卡片详情里点标签上的 ×。摘掉最后一个使用者时，这个标签跟着被清掉，标签行同步消失。

标签适合当「项目 / 客户 / 模块」用：一个进行中的项目一个标签，回头按它过滤就是这个项目当前所有待办，再配合导出就能直接贴进周报。

导出 Markdown / CSV

  1. 点操作栏齿轮 → 设置弹窗 → 导出 分区。
  2. 选「导出为 Markdown 文档」或「导出为 CSV 表格」，在保存对话框里选位置。
  3. 默认文件名是 工作计划-YYYY-MM-DD.md / .csv；导出成功后看板顶部会提示落盘路径。

两种格式的区别

格式 内容与用途
Markdown 三档按 加急 → 今天 → 以后 分节；完成项写成 - [x]；正文缩进在条目下；截图以 ![](attachments/…) 相对路径引用。适合进仓库、贴文档、写周报。
CSV 8 列（标题、正文、档位、计划日、状态、标签、截图数、更新时间），带 BOM，Excel 打开中文不乱码；正文里的逗号、换行、引号都按 RFC 4180 转义。适合二次统计。
导出的是过滤结果先清掉检索框和标签过滤，导出的才是全量。

置顶小窗模式

点操作栏分段控件的「小窗」，主窗隐藏，换成一个 默认 420×560、可拖边改大小的独立无边框窗口：始终置顶（别的窗口盖不住它），不占任务栏，Win11 下带圆角。

  • 三条泳道合并成一条列表，顺序仍是加急 → 今天 → 以后，档内沿用看板里的顺序，逾期在前、完成沉底。
  • 每条左侧是档位色条 + 小色块：加急红、今天蓝、以后灰。
  • 默认只显示内容条。鼠标移入才展开标题、三档计数、检索框和视图切换；移出即收起。正在检索时（焦点在输入框）不会收起。
  • 勾复选框直接完成；点标题回到三列看板并自动打开这条详情，数据当场重拉。
  • 移动窗口：抓顶边那条窄把手。改大小：抓左 / 右 / 下三条边与下角；下限是 300×320，到不了更小（再窄标题行会被裁、再矮列表就只剩两行）。
小窗和看板不会同时存在小窗开着时点托盘图标、或再次双击 exe，都会回到看板而不是冒出第二个小窗（应用是单实例的）。

菜单长在标题栏上：文件 / 编辑 / 视图 / 帮助。点字打开，打开后横向移到别的项直接切换，Esc 或点窗口外关闭。

明暗主题与托盘

  • 主题跟随系统：Windows 切深色，整个界面（含小窗、设置弹窗、原生日期控件）一致翻转。应用里没有手动主题开关，这是刻意的——少一个会和你系统设置打架的开关。
  • 点标题栏的 关闭 或按 Ctrl + M：窗口收进系统托盘，程序不退出；点托盘图标唤回，托盘菜单「退出」才真的退出。
  • 界面与托盘文案固定为简体中文，不随系统语言漂移；英文系统上也不会冒出 File / Edit / View。

数据位置、备份与迁移

所有东西都在一个目录里：%APPDATA%\work-plan（即 C:\Users\<你>\AppData\Roaming\work-plan）。

work-plan\
  workplan.db        SQLite 库：条目、标签、附件索引、排序号
  attachments\
    2026\10\*.png    截图按年月落盘，库里只存相对路径
  backups\
    workplan-*.db    每次启动自动备份，只保留最近 5 份
  工作计划-*.md/.csv 导出的默认落点

备份与恢复

  • 每次启动先做一次完整性检查，通过才备份，然后继续启动。
  • 想回滚：退出应用，把 backups\ 里某份复制成 workplan.db 覆盖即可（顺手把旧的 workplan.db-wal 一起删掉更干净）。

迁移到新机器

  1. 退出旧机器上的应用（托盘菜单「退出」）。
  2. 整个 work-plan 文件夹拷到新机器同一路径下。
  3. 在新机器上运行一次 exe，勾上「开机自启」（如果需要）。
为什么截图单独放目录库里只存相对路径，所以整个文件夹可以随便搬，不会出现「数据库里的绝对路径换台机器就全断」的问题。也方便你直接把 attachments 挂进网盘或仓库。

常见问题

双击 exe 没反应 / 第一次特别慢

portable 版第一次运行要把自身解包到临时目录，几秒到十几秒属正常。若被 SmartScreen 拦下，点「仍要运行」。已经有一个实例在跑时，再次双击只会把已有窗口唤回，不会开第二个。

粘贴截图没反应

先确认焦点在卡片的「记录」框里（不在正文框里的 Ctrl + V 只会当文字粘贴）。剪贴板里没有图片时，应用会提示「剪贴板里没有图片，按文字粘贴处理」，这是预期行为——它不要求你切换模式。

条目不见了

先看检索框和标签 chips 是否有残留过滤条件（检索框里按 Esc 清空）。计划日过期不会隐藏条目，只会让它标红排前；完成只会让它沉到本列底部，不会消失。

小窗移入时以前会抖，现在呢

抖动的根因是整窗都是拖拽热区，鼠标移动被系统吞掉，展开时机飘在半路；同时展开会把列表整体下移。现在拖拽热区只剩顶边一条固定把手，滚动条槽也常留，展开只发生一次位移，不再抖。

能不能多人协作 / 手机上看

不能，也不打算做。它是单人、单机、离线的工具。要给别人看就用导出 md / csv。
